## التشغيل — خمس خطوات

### 1. أنشئ المشروع

`lib/` هنا يحتوي كود التطبيق فقط، أما مجلدات `android/` و`ios/` فيولّدها Flutter:

```bash
cd mobile
flutter create --org sa.mirsad --project-name mirsad_driver .
```

الأمر يحترم الملفات الموجودة ويضيف ما ينقص.

### 2. ثبّت الحزم

```bash
flutter pub get
```

### 3. أضف الأذونات

| المنصة | الملف | انسخ منه |
|---|---|---|
| أندرويد | `android/app/src/main/AndroidManifest.xml` | [platform/AndroidManifest-additions.xml](platform/AndroidManifest-additions.xml) |
| iOS | `ios/Runner/Info.plist` | [platform/Info-additions.plist](platform/Info-additions.plist) |

كذلك في `android/app/build.gradle` اجعل:

```gradle
minSdkVersion 21
```

### 4. وجّه التطبيق إلى السيرفر

شغّل سيرفر المشروع على الشبكة لا على localhost وحدها:

```bash
# في مجلد المشروع الرئيسي
npm run dev -- --host
```

سيطبع Vite عنوانًا مثل `http://192.168.1.5:5176`. استخدمه:

```bash
flutter run --dart-define=API_BASE=http://192.168.1.5:5176/api
```

| الحالة | العنوان |
|---|---|
| محاكي أندرويد | `http://10.0.2.2:5176/api` (الافتراضي) |
| جهاز حقيقي على نفس الشبكة | `http://192.168.x.x:5176/api` |
| الإنتاج | `https://<نطاقك>/api` |

### 5. سجّل الدخول

| المستخدم | كلمة المرور |
|---|---|
| `a.mutairi` | `Driver@123` |
| `f.qahtani` | `Driver@123` |

تُنشأ حسابات جديدة من: **الموقع ← الإدارة ← المستخدمون ← إضافة** (الدور «سائق» + اختر مركبة).

## بناء نسخة الويب

النسخة المخدومة من `/driver/` على الموقع هي بناء Flutter web ملتزَم في
`public/driver/`. لإعادة توليدها:

```bash
cd mobile
flutter build web --release --base-href=/driver/
rm -rf ../public/driver && cp -r build/web ../public/driver
```

> **`--base-href=/driver/` ليست اختيارية، وحذفها يفشل فشلًا صامتًا.**
>
> بدونها يكتب Flutter‏ `<base href="/">`، فيطلب المتصفح `/flutter_bootstrap.js`
> من جذر الموقع. وهناك تلتقطه إعادة توجيه SPA في `vercel.json` وتردّ عليه بـ
> `index.html`: **‏200 لا 404**، ونوع المحتوى `text/html`. فيتلقّى وسم
> `<script>` صفحةً مكان جافاسكربت ويفشل بلا استثناء ولا رسالة في الطرفية —
> شاشة بيضاء، كونسول نظيف، وكل ملف يُخدَم بنجاح إن سألت عنه بمساره الكامل.
>
> العَرَض الذي يميّزها: عنوان التبويب يبقى `mirsad_driver` بدل «مرصاد — السائق»،
> لأن العنوان العربي يضعه التطبيق بعد إقلاعه.

> **على Git Bash في ويندوز** يحوّل MSYS الوسيط `/driver/` إلى مسار ويندوز
> (`C:/Program Files/Git/driver/`) وترفضه أداة Flutter. اسبق الأمر بـ
> `MSYS_NO_PATHCONV=1`، أو نفّذه من PowerShell.


### قرارات تستحق الانتباه

**السرعة تُحوَّل.** Flutter يعطيها بالمتر/ثانية والسيرفر ينتظر كم/س:
`(p.speed * 3.6).round()` في [tracker.dart](lib/services/tracker.dart).

**القائمة على القرص لا في الذاكرة.** النظام يقتل التطبيق دون إنذار؛ سائق عبر
منطقة بلا تغطية يجب أن تصل رحلته كاملة حين تعود الشبكة.

**`401` وحده يُخرج السائق.** أي خطأ آخر — شبكة، نقطة مرفوضة — يحتفظ بالنقاط
ويعيد المحاولة. تطبيق يسجّل الخروج عند كل انقطاع لا يصلح للعمل.

**رقم المركبة لا يُرسل.** السيرفر يقرأه من الحساب، وهذا ما يمنع سائقًا من
التبليغ باسم مركبة غيره.

**الإشعار الثابت ليس اختياريًا.** أندرويد يفرضه على أي تتبّع في الخلفية.

| أيقونة وشاشة بداية | `flutter_launcher_icons` |
| توقيع الإصدار | مطلوب للنشر في المتاجر |
