# توثيق API — تطبيق السائق (Flutter)

كل الأمثلة في هذا الملف **منسوخة من ردود السيرفر الفعلية**، لا مكتوبة من الذاكرة.

- **العنوان محليًا:** `http://localhost:5176/api`
- **العنوان في الإنتاج:** `https://<نطاقك>/api`
- كل الطلبات والردود **JSON**، والترميز **UTF-8**.

---

## 1. تسجيل الدخول

```http
POST /api/auth/login
Content-Type: application/json

{
  "username": "a.mutairi",
  "password": "Driver@123",
  "client": "app"
}
```

> `"client": "app"` **إلزامي**. بدونه يرجع السيرفر كوكي بدل التوكن، والتطبيق لا يستفيد منه.

**200 — نجاح**

```json
{
  "ok": true,
  "user": {
    "id": 7,
    "nameAr": "أحمد المطيري",
    "nameEn": "Ahmed Al-Mutairi",
    "username": "a.mutairi",
    "email": "a.mutairi@lamar.sa",
    "role": "driver",
    "groupId": 1,
    "vehicleId": 1,
    "active": true,
    "createdAt": "2026-08-08T09:40:38.268Z",
    "lastLoginAt": "2026-08-08T09:48:44.643Z"
  },
  "token": "eyJpIjo3LCJ1IjoiYS5tdXRhaXJpIiwi..."
}
```

| الحقل | استخدامه في التطبيق |
|---|---|
| `token` | يُخزَّن ويُرسل مع كل طلب بعده. **صالح 7 أيام.** |
| `user.vehicleId` | رقم المركبة — اعرضه في الشاشة الرئيسية |
| `user.nameAr` / `nameEn` | اسم السائق حسب لغة التطبيق |

**حالات الفشل**

| الرمز | الرد | المعنى |
|---|---|---|
| `400` | `username and password are required` | حقل ناقص |
| `401` | `invalid credentials` | اسم أو كلمة مرور خطأ |
| `403` | `this app is for drivers only` | الحساب ليس سائقًا |
| `403` | `account is disabled` | الإدارة أوقفت الحساب |

> رسالة واحدة للمستخدم غير الموجود ولكلمة المرور الخاطئة — عمدًا، حتى لا يُستدل على الأسماء الصحيحة.

## 2. إرسال الموقع

```http
POST /api/track
Authorization: Bearer <token>
Content-Type: application/json

{
  "lat": 24.7136,
  "lng": 46.6753,
  "speed": 62,
  "heading": 145,
  "accuracy": 8,
  "battery": 74,
  "at": "2026-08-08T09:00:00.000Z"
}
```

| الحقل | إلزامي | الوحدة | ملاحظات |
|---|---|---|---|
| `lat` | ✅ | درجة | −90 … 90 |
| `lng` | ✅ | درجة | −180 … 180 |
| `speed` | ❌ | **كم/س** | Flutter يعطيها **م/ث** — اضربها × 3.6 |
| `heading` | ❌ | درجة | 0 … 360 |
| `accuracy` | ❌ | متر | |
| `battery` | ❌ | % | 0 … 100 |
| `sos` | ❌ | boolean | زر الاستغاثة — يُطلق تنبيهًا فوريًا |
| `temperature` | ❌ | °م | −60 … 100 — لمجسّ التبريد، يغذّي تقرير SFDA |
| `humidity` | ❌ | % | 0 … 100 |
| `at` | ❌ | ISO 8601 | **وقت الجهاز — أرسله دائمًا** (انظر أدناه) |

**200**

```json
{ "ok": true, "accepted": 1, "recorded": 1, "rejected": 0, "vehicleId": 1, "status": "moving", "alerts": 0 }
```

`alerts` = عدد التنبيهات التي أطلقتها هذه النقطة. للعلم فقط — لا يتطلب تصرفًا.

`accepted` = النقاط التي فُهمت وصارت الموقع الحيّ. `recorded` = ما كُتب منها في
مسار اليوم. يقلّ `recorded` عن `accepted` حين تقع نقطة على بُعد أقل من **١٠ ثوانٍ**
من نقطة مسجَّلة بالفعل، فتُشذَّب لأنها لا تضيف تفصيلًا. **هذا ليس فقدانًا** ولا
يستدعي إعادة الإرسال — النقطة وصلت وحُسبت، والمسار وحده هو من اكتفى.

### `at` مهم أكثر مما يبدو

كان وقت الجهاز يُسجَّل ولا يُستخدم. الآن **هو التوقيت المعتمد** للنقطة في المسار
وفي التقارير وفي فترة تهدئة التنبيهات. دفعة مخزَّنة لساعة تصل في ثانية واحدة —
لو اعتُمد وقت الوصول لانضغطت الساعة كلها في لحظة، ولضاعت الرحلة من التقرير.

يُقبل `at` إذا كان بين **٧ أيام مضت** و**٥ دقائق في المستقبل**؛ خارج هذا النطاق
يُستبدل بوقت السيرفر (ساعة جهاز مضبوطة على ٢٠٣٥ ستقلب ترتيب المسار).

نقطة أقدم من آخر نقطة مسجَّلة **تُضاف إلى المسار ولا تحرّك المؤشّر على الخريطة**
— دفعة متأخرة لا يجوز أن تسحب المركبة إلى الخلف أمام غرفة العمليات.

### الدفعات — عند انقطاع الشبكة

خزّن النقاط محليًا وأرسلها معًا:

```json
{
  "points": [
    { "lat": 24.70, "lng": 46.60, "speed": 30 },
    { "lat": 24.71, "lng": 46.61, "speed": 45 }
  ]
}
```

```json
{ "ok": true, "accepted": 2, "rejected": 0, "vehicleId": 1, "status": "moving" }
```

**الحد الأقصى 200 نقطة** في الطلب الواحد. النقطة الأحدث هي التي تظهر على الخريطة.

السيرفر **يرتّب الدفعة بالأقدم أولًا** قبل معالجتها، ثم يعيد تشغيل الرحلة نقطةً
نقطة: كل واحدة تُضاف إلى المسار، وتحرّك العدّاد، وتُقارَن بقواعد التنبيه. أي أن
دفعة من ساعتين خارج التغطية تُنتج نفس المسار ونفس التنبيهات التي كانت ستُنتَج لو
وصلت النقاط لحظة بلحظة — بشرط أن يحمل كل منها `at` صحيحًا.

**ولا يهمّ متى وصلت.** دفعة مخزَّنة كلها أقدم من نقاط سبق تسجيلها تُقبل كما هي،
وكل نقطة تُدرَج في موضعها الزمني من مسار اليوم لا في آخره. فالهاتف الذي استعاد
الشبكة بعد أن أرسل غيره — أو بعد أن أرسل هو نقطة أحدث — لا يفقد شيئًا من رحلته.

### قواعد يجب أن يعرفها التطبيق

**المركبة تأتي من الحساب لا من الطلب.** لا ترسل `vehicleId` — سيُتجاهل. السيرفر يقرأه من الحساب، وهذا ما يمنع سائقًا من التبليغ باسم غيره.

**القيم الشاذة تُقصّ ولا تُرفض.** سرعة 9999 تصبح 300، بطارية 500 تصبح 100 — حسّاس معطوب لا يوقف الوردية.

**الإحداثيات المستحيلة تُرفض.** نقطة واحدة خاطئة تنقل المركبة نصف الكوكب.

**في الدفعة، النقاط السليمة تُقبل والفاسدة تُسقَط:**

```json
{ "ok": true, "accepted": 1, "rejected": 1, "vehicleId": 1, "status": "idle" }
```

**حالات الفشل**

| الرمز | الرد | التصرف في التطبيق |
|---|---|---|
| `400` | `no usable fix in this request` | تجاهل النقطة وأكمل |
| `401` | `sign in required` | **التوكن انتهى** → شاشة الدخول |
| `403` | `not allowed for this role` | الحساب لم يعد سائقًا |
| `409` | `no vehicle assigned to this driver` | أوقف الإرسال وأظهر رسالة للسائق |
| `413` | `payload too large` | قسّم الدفعة |

> **`401` هو الحالة الوحيدة التي تُخرج السائق.** الباقي: احتفظ بالنقاط وأعد المحاولة.

---

## 3. إنهاء الوردية

```http
DELETE /api/track
Authorization: Bearer <token>
```

```json
{ "ok": true, "vehicleId": 1 }
```

تختفي المركبة من الخريطة الحية فورًا. ولو انقطع الاتصال دون استدعائها، تُعتبر المركبة **غير متصلة** تلقائيًا بعد **3 دقائق** بلا إرسال.

---

## 4. استعادة الجلسة

عند فتح التطبيق ومعه توكن مخزَّن:

```http
GET /api/auth/me
Authorization: Bearer <token>
```

```json
{ "ok": true, "user": { "id": 7, "vehicleId": 1, "role": "driver", ... } }
```

`{ "ok": true, "user": null }` تعني أن التوكن انتهى أو أن الحساب أُوقف → اذهب لشاشة الدخول.

> استدعِ هذا عند كل فتح: الإدارة قد تكون **غيّرت مركبة السائق** أو أوقفت حسابه.

## 5. موقع المركبة نفسها (اختياري)

```http
GET /api/positions
Authorization: Bearer <token>
```

السائق يرى **مركبته فقط** — لا مواقع زملائه. مفيد لو أردت عرض آخر موقع مسجَّل في التطبيق.

## 6. الدعم الفني

محادثة واحدة لكل سائق مع إدارة الأسطول. لا معرّف يُرسل ولا مُستقبِل يُختار: السيرفر
يعرف صاحب التوكن، والسائق لا يملك إلا محادثته.

### قراءة المحادثة

```http
GET /api/support
Authorization: Bearer <token>
```

```json
{
  "ok": true,
  "unread": 1,
  "thread": {
    "driverId": 7,
    "driverUnread": 1,
    "staffUnread": 0,
    "updatedAt": "2026-08-09T08:41:02.117Z",
    "messages": [
      {
        "id": "0f2c…",
        "from": "driver",
        "authorAr": "أحمد المطيري",
        "authorEn": "Ahmed Al-Mutairi",
        "text": "المكيّف معطّل في المركبة",
        "at": "2026-08-09T08:39:55.402Z"
      },
      {
        "id": "7a91…",
        "from": "staff",
        "authorAr": "خالد العتيبي",
        "authorEn": "Khalid Al-Otaibi",
        "text": "وصلتنا — الورشة اليوم ٤ عصرًا",
        "at": "2026-08-09T08:41:02.117Z"
      }
    ]
  }
}
```

`unread` هو **ما لم يقرأه السائق من ردود الإدارة** — هو رقم الشارة.

### إرسال رسالة

```http
POST /api/support
Authorization: Bearer <token>
Content-Type: application/json

{ "text": "المكيّف معطّل في المركبة" }
```

الردّ يعيد `message` المضافة و`thread` بعد الإضافة، فلا حاجة لطلب قراءة بعده.

| الحالة | المعنى |
|---|---|
| `400` | `text is required` — نصّ فارغ بعد التشذيب |
| `403` | حاول الإرسال في محادثة سائق آخر (`driver` في الجسم) |

> `from` يُحسب من دور الحساب لا من الجسم — لا يستطيع أحد أن يُلبس ردًّا ثوب السؤال.
> والنصّ يُقصّ عند **2000 حرف**.

### تعليم الردود مقروءة

```http
PATCH /api/support
Authorization: Bearer <token>
```

يصفّر `driverUnread` وحده. الإدارة لها عدّادها المستقل (`staffUnread`).

## ملاحظات تنفيذية لفلاتر

### الحزم المقترحة

| الغرض | الحزمة |
|---|---|
| الموقع في الخلفية | `flutter_background_geolocation` (مدفوعة) أو `background_locator_2` |
| الموقع البسيط | `geolocator` |
| تخزين التوكن | `flutter_secure_storage` |
| قائمة الانتظار | `sqflite` أو `hive` |
| الشبكة | `dio` أو `http` |

### الوحدات — أكثر خطأ متوقَّع

`Position.speed` في Flutter بـ **م/ث**، والسيرفر ينتظر **كم/س**:

```dart
final speedKmh = (position.speed * 3.6).round();
```

### أذونات لازمة

**Android** — `AndroidManifest.xml`

```xml
<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />
<uses-permission android:name="android.permission.ACCESS_BACKGROUND_LOCATION" />
<uses-permission android:name="android.permission.FOREGROUND_SERVICE" />
<uses-permission android:name="android.permission.FOREGROUND_SERVICE_LOCATION" />
<uses-permission android:name="android.permission.INTERNET" />
```

**iOS** — `Info.plist`

```xml
<key>NSLocationAlwaysAndWhenInUseUsageDescription</key>
<string>يُستخدم موقعك لمتابعة المركبة أثناء الوردية فقط.</string>
<key>UIBackgroundModes</key>
<array><string>location</string></array>
```

### أربع مصائد تُفشل تطبيقات التتبّع

1. **إذن «طوال الوقت»** — أندرويد 11+ لا يمنحه من أول طلب. اطلب «أثناء الاستخدام» أولًا، ثم اشرح ووجّه المستخدم لإعدادات التطبيق.
2. **إشعار ثابت** — أندرويد يفرض Foreground Service بإشعار دائم. ليس اختياريًا.
3. **تحسين البطارية** — الشركات المصنّعة (شاومي، هواوي، سامسونج) تقتل التطبيق. وجّه السائق لاستثنائه.
4. **قائمة انتظار على القرص** — لا تحتفظ بالنقاط في الذاكرة فقط؛ التطبيق قد يُقتل في أي لحظة.

### HTTPS

Android 9+ يمنع HTTP العادي. أثناء التطوير على شبكة محلية استخدم `network_security_config.xml`، وفي الإنتاج Vercel يوفّر HTTPS تلقائيًا.

```

```
